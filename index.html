Move these to another device

Set these up once, then send them to your other device instead of retyping: the link/file contain your tokens, so only send them somewhere private (AirDrop, a message to yourself, etc).

Where do I get these?
  1. TMDB token: themoviedb.org → Settings → API → request a key → copy the "API Read Access Token".
  2. GitHub token: github.com → Settings → Developer settings → Personal access tokens → Fine-grained → give it read/write access to Contents on this repo only.
  3. Owner / repo: from your repo URL: github.com/owner/repo.
